🌏 Discover

A social media website with no personalized recommendation algorithms. So no more echo chamber radicalization.

There are two ways to end personalized recommendation algorithms:

  1. Block user data. No user data means no user personalization.
  2. No recommendation algorithm. User data is not used for personalization.

Any of the two is sufficient. My discover website and app does both.

For your privacy and security the discover app runs in private readonly mode by default. Discover something new everyday. Good mood and learning ahead!
